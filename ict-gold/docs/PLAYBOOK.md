# 進場劇本（Playbook）

三個劇本共用同一條管線，差別只在設定。每一個都對應一個**可以被推翻的市場故事**——
如果你說不出那個故事，那個 setup 就不該存在。

---

## 管線七關

```
① TIME      →  ② BIAS      →  ③ LIQUIDITY  →  ④ STRUCTURE
   在殺戮時段?    H4 方向?        流動性被掃?      結構轉變+位移?

                        ⑤ PD ARRAY  →  ⑥ RISK   →  ⑦ SCORE
                         折價區進場點?   停損停利?   信心分數?
```

**順序有意義，不是排版。** 「流動性」排在「結構」前面，編碼的是 ICT 真正描述的
順序：**先掃停損，才有轉折**。把兩者對調，你交易的就是另一個（而且更差的）想法。

任何一關否決，該 setup 當根就結束，並留下否決理由。這些理由會被統計成
`PIPELINE VETOES` 表——那是你最重要的除錯工具。

---

## 劇本 A：`judas_reversal`（假突破反轉）

**故事**：亞洲盤／倫敦盤堆出一個區間，紐約開盤先往一邊假突破去吃停損，
真正的行情往反方向走。

| 關卡 | 條件 |
|---|---|
| 時段 | `london`, `ny_am` |
| 流動性 | 需要 sweep，池子強度 ≥ 2（前日高低／盤別高低／相等高低點） |
| 結構 | 必須是 **CHoCH**（性格轉變），且**必須有位移** |
| 進場 | FVG 或 OB 的 **50%（CE）** |
| 區域 | 必須在該段腿的**折價區** |
| 停損 | 掃盤那根 K 的極端 + 0.35 ATR |
| 停利 | 反向最近的流動性池 |
| 最低 R:R | 2.0 |

**什麼情況代表這個故事錯了**：收盤直接穿過池子（`consumed` 而非 `swept`）——
那是真突破，不是誘多誘空，模型會自動拒絕。

## 劇本 B：`silver_bullet`（銀色子彈）

**故事**：在 10:00–11:00 紐約這個窗口內形成的失衡，演算法必須回來修補，
修補完才往當日目標前進。

| 關卡 | 條件 |
|---|---|
| 時段 | `sb_am` (10–11 NY)、`sb_pm` (14–15)、`sb_london` (03–04) |
| 流動性 | 需要 sweep，回看較短（12 根） |
| 結構 | CHoCH 或 BOS 皆可，**必須有位移** |
| 進場 | 只用 **FVG**，且取**近端**（第一個碰到的邊） |
| 區域 | 不限（時間窗本身就是過濾器） |
| 訂單有效 | 8 根 K（窗口過了就作廢） |

**為什麼進場取近端而非 CE**：這個窗口很短，等 50% 常常等不到；用近端換成交率，
代價是停損稍寬。這是一個**明確的取捨**，不是隨便選的。

---

## 劇本 C：`ote_continuation`（順勢回撤）

**故事**：趨勢日。價格回撤進 OTE（0.62–0.79）且位於折價區，然後續往當日目標。

| 關卡 | 條件 |
|---|---|
| 時段 | `london`, `ny_am`, `ny_pm` |
| 流動性 | **不需要** sweep（方向來自 HTF bias） |
| 結構 | 必須是 **BOS**（順勢續行），且必須有位移 |
| 進場 | OTE / FVG / OB 三選一，取離價格最近者 |
| 停損 | **該段腿的起點之下** + 0.5 ATR |
| 最低 R:R | 2.5（不需要 sweep 保護，所以要求更高賠率補償） |

**為什麼停損放腿的起點而不是區塊下緣**：實測發現貼著 PD array 的停損
會被回測那一下自己掃掉。這個改動是從 `mae_r` 統計看出來的，不是猜的。

## 怎麼讀一次 `explain` 輸出

```bash
python3 -m ictgold explain --csv xauusd_m5.csv --tz Europe/Athens \
    --at 2024-06-03T13:35:00+00:00
```

```
--- judas_reversal ---
  [PASS] time       in ny_am on Mon
  [PASS] bias       htf trend=bullish; htf discount (0.31); mtf aligned
  [PASS] liquidity  swept asia_low @ 2321.40
  [VETO] structure  no CHOCH bullish in last 12 bars
```

這段話的意思是：**時間對、方向對、停損也確實被掃了，但市場還沒轉身。**
早進場就是在賭，而不是在等確認。

一個月的 `explain` 輸出，比幾十小時的影片更能教會你「為什麼這裡不能進」——
因為它具體、當下、而且可以被你反駁。

## 信心分數（第 ⑦ 關）

八個因子加權成 0–1 的分數：

| 因子 | 權重 | 意義 |
|---|---|---|
| `sweep_strength` | 0.20 | 掃到的池子有多重要（相等高低點最高） |
| `displacement` | 0.15 | 有沒有留下位移 |
| `choch` | 0.10 | CHoCH 比 BOS 分數高 |
| `zone_depth` | 0.15 | 進場點在折價區有多深 |
| `killzone` | 0.10 | 時段品質 |
| `rr` | 0.15 | 超過最低要求多少 |
| `htf_bias` | 0.10 | 高時框方向強度 |
| `freshness` | 0.05 | PD array 是否未被觸碰 |

**這些權重目前是先驗值，不是結論。** 報告裡的 `BY SCORE` 分組表就是在檢查它：

- 分數越高、期望值越高 → 權重有效，可以拉高 `min_score` 換品質
- 分數跟期望值**沒有關係** → 這個分數只是裝飾，該重新擬合或直接刪掉

**「用歷史成果回歸擬合權重」這一步，才是這個系統裡唯一真正稱得上「訓練」的部分。**
在你累積到 200 筆以上樣本之前，不要動它。
