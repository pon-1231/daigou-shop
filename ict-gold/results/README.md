# 這裡放的是什麼

`backtest_xauusd_m15_2012-2022_real.txt` / `trades_xauusd_m15_2012-2022_real.json`
是一次**真實**（非合成）黃金價格回測的完整輸出。細節與重大限制寫在
[`docs/BACKTEST_REAL_2012_2022.md`](../docs/BACKTEST_REAL_2012_2022.md)。

**先看這句話**：這不是「今年」的回測，資料只到 2022-03-04。
在這個沙盒環境裡，2026 年的即時盤中資料目前抓不到（見上面那份文件的第 1 節）。

這次結果是**統計上顯著為負**（525 筆、期望值 -0.160R、t=-3.32），
不是「樣本不夠、看不出來」的那種曖昧結果。文件裡也記錄了測試過程中抓到
並修掉的一個計分 bug——修之前這個負向結果會被掩蓋掉（看起來只是雜訊）。
這份結果能證明的是「管線的測量本身是可信的」，不能證明「這個策略在今天
的黃金市場上會不會賺錢」——因為驅動這個負向數字的資料本身有時區用猜的、
時框是 M15、不是今年三個限制，細節見上面那份文件的第 5 節。

原始 CSV 沒有放進版本庫（`data/.gitignore` 排除所有 csv），
因為它是別人整理的資料集、體積大、也不確定授權範圍。
